How it works

The model reads the question.
Code does the maths.

Gemma 4 never sees your rows and never writes a number. It returns a small plan; pandas runs it on your data.

  1. 01

    Ask

    Type the question the way you would ask a person.

  2. 02

    Plan

    Gemma 4 sees only column names and returns a JSON plan.

  3. 03

    Compute

    pandas runs the plan and returns the answer, chart and code.

Under the hood

Small model call.
Plain pandas.

DataLoad is built with Gemma 4, pandas and FastAPI. The model receives your question and the column names, not your rows. Register photos are the one exception: the photo is sent once so the model can read the table.

FAQ

Questions,
answered.

Does my data leave my computer?

Only column names and your question go to the model. Rows are processed locally by pandas. Register photos are sent to Gemma 4 once to read the table.

Can the AI get a number wrong?

The model never computes numbers. It picks the operation; pandas does the arithmetic, and you can open the exact code behind every answer.

Do I need an API key?

Yes, a Gemini API key from Google AI Studio. Put it in a .env file or enter it once in the app.
